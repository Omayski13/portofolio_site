# Kristiyan Omayski Portfolio

A personal portfolio website built with Django, designed to showcase my background, skills, certifications, and professional profile as a Data Analyst, Marketing Researcher, and Python Developer.

## 🌐 Deployment
You can view the live version of the project here: [Live Demo](https://kristiyan-omayski.onrender.com/)

## 📖 Overview

This project is a modern personal website that presents:

- my professional profile and experience
- key technical skills and competencies
- certificates and achievements
- a downloadable CV
- a clean, responsive portfolio layout for GitHub and recruiter visibility

## ✅ Features

- Responsive portfolio design
- Personal profile and introduction section
- Skills and technologies showcase
- Certificate gallery
- CV download section
- Clean Django template structure
- Ready for deployment on cloud platforms

## 🛠️ Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- Render / deployment-ready setup
